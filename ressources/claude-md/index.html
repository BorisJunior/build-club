01. Le fichier

Ce que tu télécharges

Une base de `CLAUDE.md` recentrée sur la discipline de travail : qualité, sécurité, workflow, validation. Pas de dépendance à Python, pas de dépendance à un projet précis.

claude-md-base.txt 
# Guide Projet - Base de Rigueur

## Role du fichier
- imposer une maniere de travailler
- ne pas juste produire du code "qui marche"

## Exigences non negociables
- qualite minimale
- checks obligatoires
- tests quand c'est pertinent
- pas d'over-engineering

## Securite minimale
- pas de secrets en dur
- validation des inputs
- prudence sur les zones sensibles

## Regles de travail
- comprendre
- planifier
- modifier
- verifier
- corriger
- conclure

## Definition de "termine"
- besoin traite
- code coherent
- checks lances
- erreurs corrigees
02. Le prompt

Le copier, puis l'adapter

Le prompt sert à demander à ton IA de partir de cette base pour créer une version vraiment adaptée à ton repo, à tes commandes de vérification et à ta stack.

prompt-adaptation 
Je vais te donner une base de fichier CLAUDE.md.

Je ne veux pas que tu le copies tel quel.
Je veux que tu t'en inspires fortement pour creer une version adaptee a mon projet.

Conserve surtout :
- la logique de rigueur
- les exigences de qualite
- les principes de securite
- le workflow de session
- la definition de "termine"
- les garde-fous contre le code brouillon

Mais adapte le fichier a :
- ma stack technique
- mes outils
- mes commandes de verification
- mon architecture
- mes conventions
- la nature concrete de mon projet

Instructions importantes :

1. Commence par analyser mon projet si tu as acces au codebase.
2. Si certaines informations importantes ne sont pas evidentes, pose-moi les questions minimales necessaires.
3. Detecte ou propose les bonnes commandes pour :
   - formatter
   - lint
   - type-checker si pertinent
   - lancer les tests
4. Remplace les exemples trop generiques par des commandes et conventions concretes.
5. Supprime tout ce qui ne colle pas a ma stack.
6. Si mon projet n'a pas encore certains outils, propose une version raisonnable du fichier sans inventer une usine a gaz.
7. Garde le resultat concis, utile et directement exploitable.

Je veux en sortie :
- un vrai fichier CLAUDE.md final
- propre
- coherent avec mon projet
- sans sections decoratives inutiles

Voici la base :

[COLLER ICI LE CLAUDE.md DE BASE]
03. Utilisation

Comment t'en servir vite

Etape 1

Télécharge la base

Tu récupères la structure et les garde-fous essentiels sans les parties trop projet-spécifiques.

Etape 2

Copie le prompt

Tu le donnes à ton IA avec la base pour qu'elle la traduise dans le langage réel de ton projet.

Etape 3

Adapte sans surcharger

Garde les règles fortes, remplace les commandes, enlève le bruit. Le but n'est pas d'écrire un roman.
